# Images needed

Drop files into this folder using these exact names so they can be wired up automatically:

- `profile-photo.jpg` — your photo for the About Me section (roughly square, at least 400x400px so it looks sharp)
- `og-image.jpg` — the image shown when your site link is shared on social/chat apps (1200x630px, can be a simple branded graphic, doesn't have to be a photo)
- `project-1.jpg`, `project-2.jpg`, `project-3.jpg` — thumbnails for each project (square-ish, at least 200x200px — these display small, ~96x96px, so don't need to be huge)
- `favicon-source.png` — OPTIONAL: a logo/mark/headshot to generate the browser tab icon from. Skip this and a simple placeholder (e.g. initials) will be made if you don't have one ready.
